# Theme template

Every theme in themes.md uses this template. Eight required fields. No exceptions.

## Format per theme

```
## Theme N
### <Short evocative title — not a topic, a mechanic>

**Core insight.** One sentence. The behavioural mechanic, tension or contradiction at the heart of this theme.

**Why this matters.** 2–4 sentences. What the theme implies for design or strategy. Don't list — argue.

**Where and when it surfaces.** Specific moments / contexts in the interviews when this pattern appears. Use interview-ids.

**Evidence.** 3–5 verbatim quotes with interview-id attribution. Verbatim only — see cross-cutting principle #1.

> "Quote one." — Interview NN
>
> "Quote two." — Interview MM

**Prevalence.** Universal pattern (N+ interviews carry it) OR high-intensity pattern (specific subgroup — list which interviews). Be precise.

**Cross-tags.** Which other themes does this connect to? Which research questions does it answer? Which guide sections produced its evidence?

**Provenance.** EMERGENT (participant-initiated, multiple guide sections) OR PARTIALLY PROMPTED (single guide section produced most of the evidence). For partially-prompted themes, name the prompt.
```

## Evaluation section at the bottom of themes.md

After all themes, run two checks. Both go in the document.

### 1. Outliers and gaps

For each participant: are they well-represented in the themes, or is their material under-captured? List participants who carry distinctive registers no theme names.

Then: material in the data the themes do not yet name. Successful change pathways? Unique outlier stances? Anti-commercial / intergenerational / authenticity registers? Conversion stories? Their absence is also a finding.

### 2. Emergent vs prompted

Re-check each theme. For each one, was it (a) initiated by participants unprompted across multiple sections, or (b) responsive to a single guide section?

```
Theme 1 — <name>    Emergent
Theme 2 — <name>    Emergent
Theme 3 — <name>    Partially prompted (Section 5 produced most evidence)
...
```

For partially-prompted themes, the substantive finding may still hold — but the *volume* of evidence is partly an artefact of the guide. Flag it. Downstream skills will treat it accordingly.

## What this document is NOT

It is not yet personas, archetypes, or how-might-we statements. It does not produce strategic recommendations. Those are downstream artefacts. If you find yourself writing "the client should…", stop and move that to a separate strategy doc.
