# Variable template

Every behavioural variable in behavioural-variables.md uses this template.

## Format per variable

```
## V<N> · <Short name>

**What this variable measures.** One sentence. The observable behaviour, not the underlying motivation.

**Scale.**
- Low end: <description of what someone at this end looks like — concrete, observable>
- Mid: <description, with example>
- High end: <description, with example>

**Observable test.** Could you detect where a participant sits on this from a meal log, a shopping basket, or a week of decisions? If no, this is a driver not a behaviour — say so and either keep as a driver-layer variable or drop.

**What it does NOT capture.** Adjacent behaviours that look similar but should be tracked elsewhere. Be explicit — this prevents the variable from creeping outward in interpretation.

**Edge cases anticipated.** Participants you'd expect to resist clean placement on this scale, and why. (Honest variables expect edge cases; dishonest ones pretend everyone fits.)
```

## The seven variables from NV v1 (reference example)

| V | Name | What it measures |
|---|------|------------------|
| V1 | End goal | The deep motivation behind eating choices (Continuity / Caregiving / Integrity / Legacy / Autonomy / Pragmatic-survival) |
| V2 | Protein default | What gets eaten when nobody is paying attention (meat-default / mixed / plant-leaning / plant-default) |
| V3 | Planning | How food decisions get made (ad-hoc / some plan / plans week / plans systematically) |
| V4 | Preparation | How food gets onto the table (cooks raw / mixed / mostly outsourced) |
| V5 | Change history | What change has been attempted (none / reverted / oscillates / partial-stuck / fully stuck) |
| V6 | Locus of agency | Where the person believes change comes from (none/defensive / low / mid / high / principled refusal) |
| V7 | Self-describes as sustainable | The identity stance toward the label (no / partial / yes / refuses) |

V1 is the goal variable. V2–V5 are the behavioural spine. V6–V7 are attitudinal.

## Placement-difficulty test

After locking the variables, plot every interview against every variable. For each variable, list the interviews that resisted clean placement and why.

```
## Placement difficulty audit

V1 — End goal
- IP01 sits between Integrity (constrained) and Pragmatic-survival — money pressure is driving behaviour but the underlying goal is values-aligned
- IP11 is currently living Caregiving but holds Legacy as her real end

V7 — Self-describes as sustainable
- IP03 declines the label on principled grounds (not the same as the defensive "no" of IP06)
- IP05 says yes-but-not-strict — placement is fine but the meaning differs from IP09's "yes — ~70%"
```

If a variable has >1 participant resisting placement, the variable is too abstract — re-cut or drop. The participant-mapping document must show every edge case.
